Имется клиент серверное приложение.
На сервере есть следующие api:
/api/getInfo- возвращает информацию о категориях и количестве вопросов
{
  category: [
    { name: 'игры', count: 0 },
    { name: 'программирование', count: 0 },
    { name: 'кино', count: 0 },
    { name: 'история', count: 0 },
    { name: 'математика', count: 0 }
  ]
}
/api/Question- начало игры / запрос вопроса, 
передаем- 
{
    start:true,                       //начало игры
    category:['истори','математика']  //Категории определяет пользователь

}
получаем-
{
    question:{
        text: 'Год начала Второй мировой войны',
        A: '1937',
        B: '1939',
        C: '1941',
        D: '1945'
    }
}

Необходимо написать web интерфейс из следующих страниц:
1. Приветственная страница.
Выводит категории по запросу с /api/getInfo.
У каждой категории должен быть чек бокс, выбранные категории передаем.
На форме должна быть кнопка с началом игры, при нажатии переходим на форму игры и передаем категории на /api/Question с установленным флагом start

2. Cтраница игры.
Отображаем прогресс прохождения игры, текущий вопрос и варианты ответа.
При клике по варианту на /api/Question передаем 
{
    answer:'B',                       //Выбранный ответ
}
получаем очередной вопрос
{
    question:{
        text: 'Год начала Второй мировой войны',
        A: '1937',
        B: '1939',
        C: '1941',
        D: '1945'
    }
}

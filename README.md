# Структура проекта:

Папка .vscode/ содержит настройки для редактора VS Code, включая файл launch.json с конфигурациями для отладки.

Папка client/ хранит клиентскую часть приложения: index.html - главная HTML-страница, script.js - клиентский JavaScript-код, style.css - файл стилей CSS.

Папка node_modules/ содержит все установленные NPM-зависимости (автоматически генерируется).

Папка quze_core/ представляет собой нативный модуль на C++ и включает: build/ - собранные бинарные файлы, lib/index.js - JavaScript-интерфейс для работы с нативным модулем, node_modules/ - зависимости этого модуля, src/quze_core.cpp - основной исходный код на C++ (quze_core.h - хиддер модуля), test/test-server.js - тесты для модуля, CMakeLists.txt - файл конфигурации для системы сборки CMake, package.json и package-lock.json - метаданные и зависимости модуля.

Корневая директория проекта содержит: .gitignore - список игнорируемых Git-ом файлов, package.json и package-lock.json - основные зависимости и скрипты проекта, questions.json - файл с данными вопросов для игры

README.md - документация проекта

server.js - основной файл Node.js-сервера

# Структура базы данных:

Таблица категорий category:
  -id, тип целочисленной, автоинкремент 
  -name, тип строковый, уникальный


Таблица уровней сложности level:
  -id, тип целочисленной, автоинкремент 
  -name, тип строковый, уникальный

Таблица вопросов questions:
  -id, тип целочисленной, автоинкремент 
  -text, тип строковый, уникальный  (текст вопроса)
  -A, тип строковый не пустой (вариант ответа A)
  -B, тип строковый не пустой (вариант ответа B)
  -C, тип строковый не пустой (вариант ответа C)
  -D, тип строковый не пустой (вариант ответа D)
  -answer, строковый не пустой (правильный вариант ответа)
  -id_category, тип целочисленной указатель на category.id
  -id_level, тип целочисленной указатель на level.id



Назначение ключевых файлов:
 -server.js: Основной сервер Express, обрабатывает API-запросы и интегрируется с quze_core
 -quze_core/src/quze_core.cpp: Ядро на C++ для высокопроизводительных операций
 -quze_core/lib/index.js: JavaScript-обёртка для нативного модуля
 -CMakeLists.txt: Конфигурация сборки C++ модуля
 -package.json:

- Node.js 18: NODE_MODULE_VERSION=108
- Node.js 20: NODE_MODULE_VERSION=115
- Node.js 21: NODE_MODULE_VERSION=120
- Node.js 22: NODE_MODULE_VERSION=127

# Полезные команды:

-- Какая версия node используется по умолчанию?
which node - путь к программе
node -v

-- Какая версия npm используется в проекте?
cd quze_core
npm run env | grep npm

-- Просмотр локальных пакетов
npm list --depth=0 - Только пакеты верхнего уровня
npm list -g --depth=0 - Глобальные пакеты (сокращённо)

-- Зависимости пакета
npm info <пакет> - Общая информация
npm view <пакет> dependencies - Только зависимости

-- Удаление
npm un <пакет> - Локальный пакет (--save/--save-dev для зависимостей)
npm un -g <пакет> - Глобальный пакет

-- Дополнительно
npm i <пакет> - Установка
npm outdated - Проверка устаревших версий
npm cache clean --force - Очистка кэша
